# Task guides

![Type: Guide](../assets/badges/guide.svg)

[Documentation](../README.md) · [Progress](../progress.md) · [Task template](TEMPLATE.md)

Each file pairs a small task record with a tutorial for completing it. The [progress tracker](../progress.md) indexes tasks and milestones; it owns the current position and next action.

## Prepare an exercise

Use stable task IDs such as `T0001`. Start a new file from [TEMPLATE.md](TEMPLATE.md), then replace placeholders with task-specific instructions before marking the task Ready. Link dependencies, relevant specifications/decisions, and primary research sources.

Follow the walkthrough one small step at a time: each step introduces the idea it uses, shows a concrete example, names the file and action, and ends with a checkpoint. References beside the steps lead to language documentation, research, and design records. The final acceptance checks collect the evidence needed for completion.

## Record completion

Research findings are separate from task execution. A guide can be ready before implementation begins. Add actual results only after the procedure is followed, and identify how each result was established. Keep task state synchronized with the tracker.
